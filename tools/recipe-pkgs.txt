# tools/recipe-pkgs.txt -- the authoritative recipe -> package mapping.
#
# Why this file exists (2026-11-25 audit): pool-freshness associated pool
# debs with recipes through a heuristic parse and left 16 packages
# "unassociated" forever (libpcap/openssl/nocablewarn have no own
# make-deb.sh; others emit their deb from a sibling recipe).  This table is
# the explicit contract: the left column is the recipe directory, the right
# column is EVERY deb Package: name that recipe produces.  pool-freshness
# enforces both directions:
#   * every package listed here must have a deb in repo/pool (a recipe whose
#     output never reached the pool is invisible to users -- red, "run
#     make-repo.sh");
#   * every pool deb must be listed here (a pool deb no recipe claims cannot
#     be rebuilt -- red, name the recipe).
# Keep it in sync when adding a package; the completeness gate is the
# reminder.
#

# openssl4; lang/python3 ships python3 AND python314 via make-deb-314.sh).
